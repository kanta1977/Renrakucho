# ペルソナ

## 山本 静子さん（76歳）

地方都市の一戸建てに一人で住んでいます。夫は5年前に亡くなり、長男の家族は東京、長女は隣の県に住んでいて、孫が3人います。

スマートフォンは長女に勧められて持ち始めました。文字の大きさは最大にしていて、使うのは電話、カメラ、天気予報くらいです。メールは、届いたものを読む程度です。

公民館の書道教室に月2回通っていて、今年は町内会の班長もしています。老眼のため、眼鏡がないと小さな文字が読めません。指が少し震えるので、小さなボタンはよく押し間違えます。

### やりたいこと

- 孫や娘と連絡を取りたい
- 書道教室の仲間に、まとめてお知らせをしたい（今は一人ずつ電話している）
- 連絡を取る相手を、自分で増やしたり減らしたりしたい

### 困っていること

- 文字やボタンが小さくて、読めない、押せない
- 「ログイン」「タップ」などの言葉の意味が分からない
- 画面がどんどん切り替わると、どこにいるのか分からなくなって戻れない
- 間違えて押したときに、何が起きたのか分からない
- 連絡が来ても、誰からなのかすぐに分からない
- 変換を確定しようとして Enter を押したら、書きかけのまま送られてしまった

## このペルソナから決めたこと

| 困りごと | 対応 |
|---|---|
| 文字が小さい | 文字は 20〜26px、ボタンは高さ 64px 以上にする |
| カタカナ語が分からない | ログイン→「はじめる」「前にも使った」、メッセージ→「連絡」、送信→「送る」、ログアウト→「別の方に代わる」 |
| 戻れなくなる | 画面を3つにし、どこからでも「← もどる」で、はじめの画面に戻れるようにする |
| 押し間違い | 友達を外すときなどは確認を出す。送信はボタンだけにする |
| 誰からの連絡か分からない | 友達ごとに「新しい連絡 2件」と文字で出す |
| 相手を間違える | 番号で友達を探し、名前を確認してから追加する |

作らなかったもの：壁紙や文字色の変更、スタンプ、既読表示、友達申請と承認、グループ作成、通話。どれも画面や操作が増えるため、今回は入れていません。
